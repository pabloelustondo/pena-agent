# Proof of Concept / Experiments

This folder holds exploratory work, prototypes, and experimental implementations.

## Structure

- **spike-*.py** — Short experimental implementations
- **notebooks/** — Jupyter notebooks, analysis
- **prototypes/** — Throwaway prototypes
- **research/** — Research notes, literature, ideas

POCs are created to:
1. Validate feasibility before committing to specs
2. Prototype behavior before production build
3. Explore design alternatives
4. Test tool integrations and libraries

POCs should be documented with:
- What question they answer
- What was learned
- Whether it progresses to a spec or learning note
