# Learning & Feedback

This folder holds accumulated knowledge, retrospectives, and iterative improvements.

## Structure

- **retrospectives/** — Post-iteration learnings and decisions
- **decisions.md** — Architectural and process decisions with rationale
- **tools-evaluation.md** — AI tools evaluation (Copilot, Claude, ChatGPT, etc.)
- **methodology-notes.md** — SDLC2 methodology observations and refinements
- **bugs-and-fixes.md** — Patterns in bugs, root causes, preventions

Learning artifacts feed back into:
1. Context (updated assumptions, refined domain understanding)
2. Benchmarks (revised targets based on feasibility)
3. Specs (evolved requirements)
4. Tool choices and methodologies

This is how the SDLC loop closes.
