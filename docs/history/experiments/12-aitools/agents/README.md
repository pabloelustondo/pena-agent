# Agents

This folder holds agent definitions, orchestration logic, and prompt/instruction specifications.

## Structure

- **pena/** — Core PENA agent implementation
  - `prompts/` — System prompts, instructions
  - `tools/` — Tool definitions, schemas
  - `memory/` — Memory system, context management
- **orchestration/** — Multi-agent workflows, routing, composition
- **evaluation/** — Agent evaluation, testing, quality metrics
- **prompts/** — Shared, reusable prompt templates and instruction sets

This folder treats prompts and specifications as first-class code artifacts.
