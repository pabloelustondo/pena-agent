# 25 Glossary

## PENA Agent

The root system that ingests information, evaluates it against context, summarizes it, produces digest output, and records execution evidence.

## Golden Path

A deterministic, realistic end-to-end execution scenario used to prove structural coherence.

## Walking Skeleton

A minimal executable system that connects the real architectural components while using simplified internal behavior.

## Stub

A deterministic replacement for a real component.

## Context Snapshot

The immutable context package used for one run.

## Scored Article

The result of trust, quality, and relevance evaluation.

## Digest Item

The final user-facing information unit produced by PENA.

## Execution Trace

A record of what happened during a run.

## SDLC2

A spec-driven, AI-assisted, knowledge-centric, iterative software engineering lifecycle.

## STAV

Specs, Tests, AI, Vibe.
