# Documentation

This directory holds all project documentation for the PENA project.

---

## Layout

### `product/`

Product-level context: what PENA is, who it is for, what it should do.

- `product/context/` — Domain description, assumptions, constraints, tools under evaluation
- `product/benchmarks/` — Success criteria and target behaviors (to be populated)
- `product/specs/` — Feature specifications (to be populated)

### `sdlc2/`

SDLC2 lifecycle artifacts. Follows the knowledge-centric engineering methodology used on this project.

- `sdlc2/01-context/` — Context phase: domain, assumptions, constraints, tools
- `sdlc2/03-benchmark/` — Benchmark definitions
- `sdlc2/04-planning/` — Planning documents and handovers
- Additional numbered phases (02, 05–11) will be populated as the project progresses.

See `.instructions.md` at the repository root for a description of the SDLC2 loop.

### `history/`

Historical record of experiments, observations, and prior work. **Read critically — content here is not automatically current or canonical.**

- `history/experiments/` — Past design experiments, UML drafts, prototype explorations
- `history/learning/` — Retrospectives and learning notes (to be populated)
- `history/sdlc2-observations/` — Early SDLC2 phase stubs and structural observations

---

## Navigation

Start at the root [README](../README.md) for a project overview, then navigate here based on what you need:

- Understanding what to build → `product/`
